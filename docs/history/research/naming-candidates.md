# Recorder 历史命名候选

状态：历史讨论。原归档日期：2026 年 10 月 23 日；整理日期：2026 年 10 月 24 日。阅读时机：用户主动重新讨论命名时。

用户已决定继续使用 Recorder。以下保留先前的命名创意，供未来主动重新讨论命名时参考，不作为当前更名建议。商标、域名及软件重名尚未核查。

| 候选 | 侧重点 | 原讨论中的取舍 |
| --- | --- | --- |
| 拾存 | 随手收集，妥善保存 | 贴近快速输入和本地资料库，主动管理的含义较弱 |
| 存序 | 保存资料，并让资料有秩序 | 覆盖分类、归纳、日程和订阅管理，稍偏工具感 |
| 纳川 | 容纳工作生活中的多种信息 | 名称空间宽，首次接触需要一句产品说明 |
| 万匣 | 装下不同形态的数据 | 资料容器的形象直接，容易偏向文件收纳 |
| 拾录 | 随手记录生活与工作 | 易理解，但对文件管理的表达较弱 |
| 迹库 | 保存经历和资料，便于找回 | 适合强调历史与追溯，快速捕获的意味较弱 |
| KeepDock | 集中接收和保存内容的入口 | 英文项目名候选，偏向资料收集工具 |
| RecordNest | 记录与资料的个人空间 | 含义直观，英文名称较长 |
