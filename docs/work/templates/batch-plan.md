# 批次计划模板

状态：可复制模板，非实际任务。阅读时机：规划者创建一批已授权工作或整理整合报告时。使用时复制到具体批次的 README.md，填写占位项，删除不适用说明。

## 基本信息

- 批次：`Bxxx` / 名称 / 日期。
- 状态：待决策 / 待开始 / 进行中 / 待整合 / 需修复 / 已合并 / 取消。
- 用户目标与授权范围：填写原意及可观察结果。
- 决策依据：链接当前有效文档；区分用户决定与规划者的工程选择。
- 未决定项：列出分歧、推荐及影响，标明阻塞哪些任务；无则写无。
- 规划整合者：会话或责任说明；不假设所有 AI 会话共享消息。
- 派工基线：记录合入规划文档后的完整提交 SHA；基线公布在派工消息及任务实际开工记录中。不要在同一个提交中填写它自身的 SHA。
- 合并模式与目标：默认各任务 PR → `main`；如必须整体交付，写明 `integration/<batch-id>` 及理由。

每张任务卡使用真实 Markdown 链接并说明何时阅读；下面的占位文字不算正式登记。任务名称仅为格式，不代表已经选择某项功能。

| 任务 | 任务卡及阅读时机 | 允许修改范围 | 前置任务 | 可并行关系 | 分支 | 状态 |
| --- | --- | --- | --- | --- | --- | --- |
| Bxxx-T01 | 实际任务卡链接；开始/验收该任务时读 | 待填写 | 待填写 | 待填写 | 待填写 | 待开始 |
